# EuLearn — dokumentacja projektowa

Aplikacja mobilna (Flutter) dla dzieci 6–10 lat do nauki mapy świata: położenie krajów, granice i sąsiedzi, stolice, flagi. Punktem wyjścia jest „mój kraj” wybrany przez dziecko. Interfejs po polsku i angielsku; przy okazji dziecko osłuchuje się z angielską wymową nazw krajów i stolic.

| Dokument | Zawartość |
|---|---|

| [02-design-wizualny-i-ux.md](02-design-wizualny-i-ux.md) | Styl, kolory, typografia, mapa, ruch, dźwięk, zasady UX dla dzieci, ekrany |
| [03-zalecenia-flutter.md](03-zalecenia-flutter.md) | Architektura, pakiety, dane mapy, renderowanie, silnik gry, testy — wiążące przy implementacji |
| [04-plan-wdrozenia-i-multiplayer.md](04-plan-wdrozenia-i-multiplayer.md) | Etapy, zakres MVP, multiplayer, ryzyka, decyzje otwarte |

Kolejność czytania przed implementacją: 03 → 04 (etap 0) → 01/02 w miarę potrzeb.
